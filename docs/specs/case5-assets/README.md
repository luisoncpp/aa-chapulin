# case5-assets

Contratos por activo para la regeneración y aceptación de los assets generados del Caso 5.

- `<asset>.md` — hoja de hechos de un activo: qué debe contener, qué no puede contradecir y con qué otros activos se regenera. Generada con el skill [[.agents/skills/asset-facts/SKILL.md|asset-facts]] (`/asset-facts <asset-id>`).
- `new-assets.md` — activos nuevos que el guion necesita y §23 no declara.

La fuente de verdad de cada hoja es el spec (`docs/specs/case-5-el-tomo-trece.md`), nunca las imágenes.
