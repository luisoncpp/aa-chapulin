# Internationalization

Provides runtime localization support for Spanish and English text across UI controls, modals, and notifications. Coordinates with [[index.ts]] to dispatch locale changes to game engine components. Supplies strongly-typed translation dictionaries for bilingual storytelling and investigation dialogue.
